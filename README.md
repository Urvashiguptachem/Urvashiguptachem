# Urvashi Gupta · Chemistry Notes

Illustrated spectroscopy notes (Fundamentals, UV-Vis, IR, Raman, NMR) by Urvashi Gupta, with interactive tools and quizzes.

Static multi-page site: home `index.html`, topic pages (notes, tools, quiz) in `fundamentals/`, `uv-vis/`, `ir/`, `raman/`, `nmr/`, shared `styles.css` + `app.js`. No build step.

- Add a note: put `NN.jpg` and `NN-thumb.jpg` in `notes/<topic>/` and add an entry to `NOTES` in `app.js`.
- Edit name/socials: `CONFIG` block at the top of `app.js`.
- Deploy: import this repo on Vercel with Framework preset **Other**, no build command, output directory `./`.
